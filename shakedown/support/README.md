# Disposable support companions

This directory contains the versioned, non-private artifacts for Artie's
disposable Mica and Lumen peers:

- `companions.template.json` is the canonical fleet identity and runtime-path
  contract.
- `cards/*.json` are supported JSON character-card imports with synthetic
  identities and no channel accounts.

The stand-up, acceptance, and teardown procedure lives only in
[`docs/shakedown.md`](../../docs/shakedown.md#support-companions).
